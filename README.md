# weirdest-job-title-showdown

A deterministic Node 22 program that writes one original job title for [make.fun](https://make.fun/)'s Weirdest Job Title: Blind Judge Showdown.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The grader sets `MAKEFUN_OUTPUT_DIR` to `/output`. The program writes UTF-8 `entry.txt` there and nothing else.
